# python-project
化學反應動力學模擬器
(1)程式功能與原理: 這次term project 透過Python與SciPy套件建立了一個可互動的反應動力學模擬器，能夠模擬不同反應級數下濃度隨時間的變化圖，並且以動畫的方式呈現
(2)使用方式: 使用者需輸入反應級數、反應速率常數、初始濃度以及反應時間，按下執行後便會跑出濃度與時間的關係圖並且以動畫的方式呈現
(3)程式的架構
首先先匯入套件 numpy scipy 以及 matplotlib 接者撰寫讓使用者輸入反應級數、反應速率常數、初始濃度以及反應時間 然後做檢查，排除0,1,2級外的反應;k值小於0的問題;初始濃度小於0以及時間不小於0的問題。
接著定義反應速率以及不同反應級數的公式並建立微分方程。使用套件solve_ivp調整時間步長。最終再透過plot畫上靜態的濃度時間圖以及動態的濃度時間圖
(4)開發過程
先了解反應速率的公式，再上網查詢有關套件的應用，像是使用scipy解微分方程以及使用matplotlib.animation中的FuncAnimation讓靜態的圖動態畫並學習一些程式碼的功能，像是raised可以在偵測到錯誤訊息停止執行等等觀念
